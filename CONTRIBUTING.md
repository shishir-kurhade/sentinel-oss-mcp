# Contributing to Sentinel MCP

Thank you for your interest in helping improve Sentinel MCP! 

## How to Contribute

1.  **Report Bugs**: If you find a security hole or a bug, please open an issue with a clear description and steps to reproduce.
2.  **Suggest Features**: Have an idea for a new defense layer or industry constitution? Let's discuss it in the issues!
3.  **Submit Pull Requests**:
    -   Fork the repository.
    -   Create a feature branch (`git checkout -b feature/amazing-feature`).
    -   Commit your changes (`git commit -m 'Add some amazing feature'`).
    -   Push to the branch (`git push origin feature/amazing-feature`).
    -   Open a Pull Request.
